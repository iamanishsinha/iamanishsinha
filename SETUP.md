# Setup — Editorial Dark GitHub Profile

This build intentionally avoids the typical AI-generated "black + cyan + purple neon glassmorphism" look.

## Visual system

Primary:
- near-black
- deep navy
- dark blue
- steel/light blue
- indigo

Secondary:
- maroon
- dark red
- dark green
- warm off-white

The design uses hard-edged editorial panels, thin rules, asymmetry and restrained typography rather than glowing cards.

## Before publishing

Replace:
- `YOUR_X_URL`
- `YOUR_PORTFOLIO_URL`
- `YOUR_EMAIL@example.com`

## Repository

Create a public profile repository named exactly:

`iamanishsinha`

## Snake

Run the GitHub Action once manually after pushing:

Actions → Generate contribution snake → Run workflow

The hero is a local animated GIF. The technology strip and India element are local assets.
